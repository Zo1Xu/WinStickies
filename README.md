# WinStickies

轻量的 Windows 桌面便签。每张便签都是独立窗口，可自由移动、调整大小、收起为标题条，并自动保存到本机。

无需安装、登录或联网。支持 Windows 10 / 11，运行环境为 .NET Framework 4.8。

## 下载与使用

1. 在本仓库的 **Releases** 页面下载 `WinStickies-v版本号-portable.zip`。
2. 解压到一个可写入的文件夹，再双击 `WinStickies.exe`。
3. 启动后会显示托盘图标及“启动成功”通知。图标可能位于任务栏的隐藏图标区域。
4. **双击托盘图标**新建便签，**右键托盘图标**打开管理菜单。

## 功能

- **独立便签**：每张便签单独移动、缩放和收起；展开与收起状态分别记住尺寸。
- **标题编辑**：双击标题文字或按 `F2` 修改，`Enter` 完成、`Esc` 撤销；清空后自动使用正文首行。
- **快速收起**：双击标题旁的空白处，或点击左侧箭头，收起 / 展开当前便签。
- **文字格式**：在“…”菜单设置正文字号；支持字号快捷键与选中文字加粗，格式自动保存。
- **六种颜色**：每张便签可独立选择纸张颜色。
- **归档与搜索**：暂时不用的便签可归档，在托盘或总览中重新打开；总览支持标题、正文搜索及模式筛选。
- **本地保存**：自动保存内容、标题、格式、颜色、位置及显示状态，并保留上一个成功保存版本。

### 三种显示模式

| 模式 | 行为 |
| --- | --- |
| 普通悬浮 | 普通独立窗口，切换到其他应用后可被遮挡。 |
| 始终置顶 | 保持在普通应用窗口上方。 |
| 桌面附着 | 留在 Windows 桌面层，可用 `Win+D` 查看桌面。 |

点击标题栏的模式按钮切换，也可从托盘或总览操作。每张便签独立设置。

### 关闭、归档与退出

点击便签右上角 **×** 后，可以选择 **删除**、**归档**或**取消**。

- 归档保留内容和窗口状态，重新打开后恢复。
- 删除移除当前便签。
- 关闭总览后，便签仍会继续运行。
- 完全退出软件：右键托盘图标 → **退出 WinStickies**。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+N` | 新建便签 |
| `F2` | 修改当前便签标题 |
| `Ctrl++` / `Ctrl+-` | 放大 / 缩小正文字号，兼容小键盘；`Ctrl+=` 也可放大 |
| `Ctrl+B` | 切换选中文字的加粗；无选区时影响后续输入 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做正文编辑与格式修改 |
| `Ctrl+Shift+C` | 收起 / 展开当前便签 |
| `Ctrl+Shift+L` | 打开总览 |
| `Ctrl+S` | 提交保存请求 |
| `Ctrl+F` | 在总览中搜索 |

## 数据与升级

数据默认保存在 `WinStickies.exe` 旁的 `data` 文件夹中：

- `notes.json`：便签内容和状态。
- `notes.json.bak`：上一次成功保存的备份。

修改后约 500ms 自动保存。保存失败时会提示并重试；遇到损坏数据时保留原件，并尝试从备份恢复。

**升级前从托盘退出程序，备份 `data` 文件夹，再替换 exe。保留原有 `data` 文件夹，即可继续使用已有便签。**

也可以指定数据目录：

```powershell
.\WinStickies.exe --data-dir "D:\MyNotes"
```
